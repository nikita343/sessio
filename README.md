# Sessio

Practice software for independent psychologists and therapists — Poland first.
Booking page with BLIK / card / Przelewy24 prepayment, peer-to-peer private video room, on-device voice-memo notes drafted into Art. 28 records, and an admin assistant. 0% commission.

- `apps/web` — landing site (usesessio.com)
- `apps/app` — product (app.usesessio.com): therapist dashboard + public booking pages

Stack: Next.js 16, Supabase (EU), Stripe Checkout, WebRTC + Supabase Realtime signalling, Whisper in the browser (transformers.js), Vercel AI Gateway.
